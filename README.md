# FedEx-Logistics-Analysis-Dashboard_Excel
📦 FedEx Logistics Analysis Dashboard – Excel
📊 Project Overview

The FedEx Logistics Analysis Dashboard is an interactive Excel-based data analytics project designed to analyze shipment performance, freight costs, commodity value, delivery delays, shipment modes, vendors, countries, and monthly logistics trends.

The dashboard transforms logistics data into meaningful business insights and KPIs using Microsoft Excel, Pivot Tables, Pivot Charts, Slicers, and advanced Excel formulas.

The project demonstrates how Excel can be used to perform data cleaning, analysis, visualization, KPI tracking, and business reporting for a logistics and supply-chain environment.

🎯 Project Objectives

The main objectives of this project are:

Analyze overall shipment performance
Track total shipment volume
Monitor total freight costs
Analyze commodity value
Measure on-time delivery performance
Identify shipment delays
Compare different shipment modes
Analyze freight costs by country
Analyze shipment volume by vendor
Identify monthly trends in logistics performance
Build an interactive management dashboard

📌 Dashboard KPIs

The dashboard provides the following key performance indicators:

🚚 Total Shipments

7,981

Represents the total number of shipments included in the analyzed dataset.

💰 Total Freight Cost

$67.29 Million

Represents the total freight cost associated with the shipments.

📦 Total Commodity Value

1.46 Billion

Represents the total value of commodities associated with the shipments.

⏱️ Average Scheduled Delay

-4.74

Represents the average scheduled delivery delay measure calculated from the dataset.

✅ On-Time Rate

86%

Represents the percentage of shipments meeting the defined on-time delivery criteria.

Note: KPI values may change depending on the selected filters/slicers.
